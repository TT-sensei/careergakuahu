# キャリア探究ナビ

小学6年生のキャリア教育「未来のわたしをデザインする」の学習ガイドです。全15時間の探究の流れに沿って、仕事や自分の将来について調べ、考え、発表の準備まで進められます。

公開ページ： https://tt-sensei.github.io/careergakuahu/

## 構成

- index.html：入り口ページ
- career-main-v3.html：学習ガイド本体（全15時間）
- shigototane.html：仕事の種図鑑（ガイドからリンクしています）
- presentation.html：発表のお手本（assets/presentation-example.pdf を表示します）
- career-main-v2.html：旧版（入り口からはリンクしていません）

## 学習の進め方

- 第1時間から第15時間までのガイドに沿って進み、1時間ごとの進み具合をチェックできます。
- 第5〜7時間には「AIに聞いてみよう」があります。AIへの質問文（プロンプト）を表示してコピーする形で、このサイトから外部のAIを呼び出すことはありません。AIの答えをそのまま信じないための注意書きも付けています。
- 調べ学習の資料として、外部の職業紹介サイト（マイナビ・学研・job tag・13歳のハローワーク）へリンクしています。

## データについて

進み具合はサーバーへ送信されず、この端末のブラウザ（localStorage の `careerDone`）にだけ保存されます。
